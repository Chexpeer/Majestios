# Développement commercial

**Rôle du dossier :** coordonner la chaîne Détecter → Qualifier → Identifier → Contacter → Transformer → Capitaliser.

Page existante associée : `developpement-commercial.html`.

Sous-thèmes fonctionnels : stratégie commerciale ; qualification et ciblage ; plan d'action ; relation client ; mesure des résultats.

Règle : le développement commercial est le domaine transversal ; prospection, CRM et Business Intelligence restent des fonctions distinctes qui le soutiennent.
