# CRM

**Rôle du dossier :** organiser les entreprises, contacts, interactions, prospects, opportunités et actions de suivi dans une vue cohérente.

Pages existantes associées : `crm.html`, `suivi-commercial.html`.

Sous-thèmes fonctionnels : organisations et contacts ; historique d'interactions ; pipeline commercial ; tâches et relances ; capitalisation.

Règle : ne pas annoncer comme opérationnelles les fonctions de persistance, de synchronisation ou d'automatisation qui ne sont pas effectivement connectées.
