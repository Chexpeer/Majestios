# Marchés privés

**Rôle du dossier :** organiser les opportunités privées et les signaux d'affaires sans les confondre avec les marchés publics.

Page métier associée : `marches-prives.html`. Les pages `bodacc-veille-entreprises.html` (dossier 03) et `sous-traitance.html` sont des parcours connexes, pas des pages canoniques de ce dossier.

Sous-thèmes fonctionnels : consultations et opportunités privées ; sous-traitance ; immobilier professionnel et autres sources à connecter. Les cessions et reprises sont des signaux de veille économique, à qualifier avant de les présenter comme opportunités.

Règle : afficher clairement la source et l'état du connecteur. Une publication BODACC est un signal légal/économique, pas un appel d'offres.
