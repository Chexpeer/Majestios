# Dossiers fonctionnels MajestiOS

Ce répertoire matérialise l'organisation fonctionnelle du produit. Il contient les dossiers thématiques et leurs règles de périmètre ; il ne remplace pas les pages HTML de l'application.

Ordre de référence de l'immeuble d'accueil :  
01 Marchés publics → 02 Marchés privés → 03 Veille économique → 04 Prospection → 05 Développement commercial → 06 Accompagnement aux appels d'offres → 07 Salon virtuel → 08 Espace entreprises → 09 CRM → 10 Business Intelligence.

Voir `../DOSSIERS-MAJESTIOS.md` pour la correspondance des dossiers avec les pages existantes, les règles de conception et les critères anti-régression.

Les pages HTML restent provisoirement à la racine du dépôt pour préserver les chemins relatifs et le build statique. Ne pas les déplacer sans chantier distinct de migration des routes et de la configuration de build.
